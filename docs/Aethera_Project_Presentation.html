1. Problem Statement & Vision

University students face heavy information overload from lengthy textbooks, research papers, and complex lectures, requiring immense time to summarize notes, practice exams, and format citations.

🚀 The Vision

Deliver a unified, zero-latency academic assistant that automates summarization, exam generation, mind mapping, and flashcards while offering live Notion synchronization.

⚡ Key Differentiator

Leverages Groq API Llama 3.3 70B for sub-second streaming inference, coupled with local document parsing (PDF/DOCX) for complete student privacy.

2. Functional Specifications

📚 Academic Tools (17+)

Summarizer, Exam Generator, Concept Breakdown, Study Planner, Essay Assistant, Citation Builder, Smart Translator, and Cornell Notes.

💡 Interactive Learning

Flashcard Generator (Anki export), SVG Mind Map Visualizer, Quick Quiz Engine with instant feedback, and AI Chat Assistant.

📊 Productivity Suite

GPA Calculator (Semester/Cumulative), Pomodoro Timer, History Manager, and Notion Workspace Live Sync.

3. Architecture & Tech Stack

Client Layer (SPA)

Vanilla JavaScript & HTML5 Glassmorphic UI with PDF.js & Docx local text extractors.

Server Layer

Node.js & Express REST API Server managing endpoints, security headers, and AI proxying.

Database Layer

SQLite local database (17 structured schemas) & Supabase PostgreSQL with pgvector support.
